Forget dealing with the limitations of RenderTargets to design your Minimaps, which are performance heavy for larger worlds. This system can handle thousands of Points of Interest at a time without affecting the performance, and is designed keeping Open World RPGs in mind, however the flexibility and ease of implementation allows you to use this system in any kind of game you want, from archviz projects to real time strategy games.

Actors represented as Points of Interest in the Minimaps and Maps are implemented via Datatable and each POI Actor class added to the Datatable has its own set of unique properties, making it simpler to add a variety of different POI having different functionalities.

FEATURES

  1. Texture Based Minimap System.
  2. Transition between multiple Map regions in same level.
  3. Datatable driven Static and Dynamic Points of Interest.
  4. POIs can be displayed based on Visibility radius, or can be set to always visible.
  5. POIs not in bounds can be shown via custom marker at the edge of the Minimap.
  6. Centrical Player Position, where player marker always stays at the center.
  7. Fixed Zoom vs User Defined Zoom Level for Minimap.
  8. Rectangular and Circular Minimap, with AutoRotate feature to rotate the map with player rotation.
  9. Minimap Texture masking for non rectangular Bounds.
  10. Interactive Map , with Zoom and Pan functionalities.
  11. POIs for Map can have visibility based on Zoom Level.
  12. Custom ToopTip Widgets for Points of Interest in Map.
  13. Tested Multiplayer Support.
  14. Waypoint Markers can be added in map for navigation, which can be custom marker, or specific to the selected Point of Interest.
  15. Customizable Navigation system, allowing user to add one or many Navigation Markers in the world, to display the location of the destination.
  16. Navigation Out of Bounds notification, to display custom markers when player camera view is not looking at the destination.
  17. Custom destination actors can be added to highlight the destination from a distance.
  18. Navigation exist actors as optional local destinations, when target is at a different Bounds area.
